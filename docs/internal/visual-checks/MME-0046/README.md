# MME-0046 Visual Checks

This folder stores HTML preview reading-polish artifacts.

- `normal-html-reading-desktop.png` proves the standalone HTML artifact opens as a clean reading surface without a permanent debug strip.
- `normal-html-reading-constrained.png` proves the preview uses the available constrained viewport without obvious gutters or nested scroll traps.
- `html-preview-details-open.png` proves sandbox tokens, script state, document target, and save truth remain discoverable through a discreet details affordance.
- `html-preview-script-blocked.png` proves hostile inline scripts remain blocked while the preview still renders.
