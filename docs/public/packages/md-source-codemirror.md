# CodeMirror Source View

`@momentarise/md-source-codemirror` provides the source-mode editor layer.

## Use It For

- Markdown source editing;
- keymap composition;
- read-only state;
- editor-grade baseline behavior;
- attaching CodeMirror to a headless session.

## Boundary

CodeMirror stays in this view package. Core packages stay independent from editor UI libraries.
