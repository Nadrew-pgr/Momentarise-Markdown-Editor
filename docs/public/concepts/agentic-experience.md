# Agentic Experience

Momentarise Markdown Editor treats agent support as a documentation surface, not a hidden product claim.

The public docs site is built from the same Markdown files that humans read. Agent actions copy or open that Markdown with explicit instructions, so an assistant can reason from the durable source instead of a lossy web scrape.

## What Ships Now

### Docs-Site Actions

- raw Markdown for every page at `/docs/<page>.md`;
- copy page as Markdown;
- copy current section from the page outline;
- copy page as an LLM prompt;
- Open-in-chat entries for common assistant tools, with copy fallback when a deep link is unreliable;

### Machine-Readable Discovery

- generated `llms.txt` and `llms-full.txt`;
- repository-owned generated agent artifacts at `docs/agent/README.md`, `docs/agent/manifest.json`, `docs/agent/actions.json`, and `docs/agent/skills`;
- a generated machine-readable product/status profile at `docs/agent/product.json`;
- stable public discovery endpoints for the LLM indexes, agent manifest, action descriptors, and skill files;
- reusable action descriptors for page-source, copy, prompt, Open-in-chat, and future host actions;

### Local Tooling

- `@momentarise/md-cli` checks for local and agent-driven workflows.

## Prompt Contract

Every copied prompt includes the page content plus rules for safe use:

- use web search if available;
- prefer official docs;
- cite sources when browsing;
- respect MME's Markdown-as-source constraint;
- do not assume JSON or block database persistence;
- separate framework-neutral guidance from host-specific integration.

Markdown remains the source. The prompt is a transport format.

## Files For Agents

`llms.txt` is the short index. It lists important pages and stable URLs.

`llms-full.txt` is the larger context bundle. It concatenates public Markdown pages in navigation order and keeps page boundaries visible.

Both files are generated by `scripts/generate-llms.mjs` and checked by `npm run test:llms-sync`.

`docs/agent/manifest.json` records generated skills, source docs, package metadata, and the public-only source hash.

`docs/agent/product.json` provides one deterministic product identity, audience, durable-source, integration, package-status, licensing, guarantee, non-capability, and canonical-URL profile.

`docs/agent/actions.json` describes page actions independently from the docs site's UI chrome, so future hosts can render the same action contract differently.

`docs/agent/skills` contains Codex-style `SKILL.md` artifacts for MME docs usage, adoption evaluation, migration help, package selection, AI/privacy boundary checks, and docs-to-implementation prompts. They are committed repo artifacts, not installed automatically into a user's global Codex skills folder.

`docs/agent/README.md` is the generated artifact index. It links the public web endpoints while the manifest keeps repository paths for local tools.

## Stable Web Endpoints

- `https://momentarise.dev/llms.txt` — short framework and documentation index;
- `https://momentarise.dev/llms-full.txt` — complete generated public Markdown context;
- `https://momentarise.dev/agent/README.md` — agent artifact index;
- `https://momentarise.dev/agent/product.json` — machine-readable product and status profile;
- `https://momentarise.dev/agent/manifest.json` — artifact and skill manifest;
- `https://momentarise.dev/agent/actions.json` — reusable docs action descriptors;
- `https://momentarise.dev/agent/skills/<skill-id>/SKILL.md` — individual generated skills;
- `https://momentarise.dev/docs/<page>.md` — raw source for any public docs page.

The rendered site also publishes `robots.txt`, `sitemap.xml`, canonical metadata, and source-code structured data. These improve discovery; they do not guarantee indexing, ranking, citation, or agent installation.

## CLI Workflow

Use `@momentarise/md-cli` when an agent needs machine-readable local proof:

```bash
node packages/md-cli/dist/index.js inspect README.md --json
node packages/md-cli/dist/index.js check --json
node packages/md-cli/dist/index.js format README.md
```

The CLI resolves Document Access Policy before it reads, formats, exports, or writes. It is meant to make local automation safer, not to bypass host rules.

## Not Shipped Yet

hosted Ask AI, semantic docs search, live edit-on-GitHub actions, live issue filing, automatic global skill installation, and public marketplace distribution are future public-release work.

Do not describe those as current MME capabilities until they are promoted into an implementation issue and proven.
